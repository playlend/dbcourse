FerricDB Course

Database Systems, Built From Scratch

A concept curriculum on database internals paired with a milestone project: build FerricDB, a toy Postgres in Rust that real psql clients can talk to.

This course teaches database internals the way CMU 15-445 and Berkeley CS186 do — buffer pools, B+Trees, query execution, MVCC, ARIES recovery — but organizes everything around one running system that you build yourself. Every concept module is paired with a project milestone, so theory is applied immediately. By the end, your database speaks the PostgreSQL wire protocol: psql -h localhost -p 5433 connects to your code.

Who this is for

Comfortable programmers who know SQL basics and Rust at the level of The Rust Programming Language book (ownership, traits, error handling, basic concurrency). No prior database-internals knowledge is assumed. Module 0 includes a Rust refresher reading list.

The recommended path

Concept modules (blue) are numbered by topic area, mirroring the CMU lecture order. Project milestones (green) are built strictly in sequence — each builds on the last. The two interleave: read the module, then build its milestone.

How to work through the course

  1. Follow the recommended path above: read a module, then build its milestone.
  2. Each module page ends with a Milestone link telling you what to build; each milestone page starts with Required reading pointing back at its module and the primary sources.
  3. Run the provided tests as you go — every milestone lists exactly which test group to un-ignore (e.g. cargo test -- --include-ignored ms2_).
  4. Everything cites primary sources — course notes from CMU and Berkeley, the ARIES and Selinger papers, PostgreSQL documentation and internals guides. The citations are the "go deeper" trail; use them.

All pages work offline via file:// — external links appear only as citations and further reading. Built as an original curriculum; primary sources are cited per page and collected on each page's "Primary sources" list.
